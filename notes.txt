installatie:
install Visual Studio Code en Node.js
in VSCode, installeer de plugin voor Playwright Test for VSCode

open Visual Studio Code als admin
open een folder waar je in wilt werken bv C:/repos
open een terminal in VSCode (Terminal > New Terminal)
voer deze commands uit:
npm init playwright@latest
npx playwright test --ui

Opdrachten
01 - unit test
Schrijf een unit test die onderstaande functie valideerd. 
const addNumber = (a: number, b: number): number => a + b
Gebruik de 'test' functie van playwright.

02 - API test
Schrifj een API test die naar google.com gaat en valideerd dat de request succesvol terugkomt.
Gebruik de 'test' functie van playwright met het request object in de callbackfunctie. 

0301 - Basic E2E test
Schrijf een test die naar https://practicesoftwaretesting.com/ gaat. Vanhieruit naar de contact pagina navigeert. Valideer dat de pagina 'Contact' als title heeft dat de url op '/contact' eindigt.
Gebruik de 'test' functie van playwright met het page object in de callbackfunctie.
